How We Help — the navigation system

Two elements, each doing one job, identical on all three pages. The sticky pill is wayfinding for this page. The Path module is the journey across all three. They never compete.

Element 1 — the floating pill (sticky, one per page)

Same pattern your other service pages already use: phase name + this page's section anchors + Schedule a Call. The only journey touch is a small "Step 2 of 3" tag (with three dots) beside the name — the one persistent "you are here." It scrolls to the Path module. Nothing else changes between pages.

Why this works (and what Apple would do)

  • The sticky bar stays single-purpose. Apple never stacks two sticky navs. The pill is sections + CTA; the journey is content. No competition, no double bar.
  • One persistent cue, not a whole second bar. The "Step 2 of 3" tag is enough to say "you're on a path" without crowding the anchors.
  • Consistency is the connection. Identical pill + identical Path module on all three pages is what makes them read as one experience.
  • It scales. Pricing and any other journey-adjacent page can carry the same pill + module without redesign.
