## Notes

- **Bio photos**: Individual team member headshots are served from the `Minyan_Photos` directory. The download script generates URLs for all 35+ team members using the standard naming pattern. A handful of members link to LinkedIn instead of an impactplus.com bio page, so their headshots may not follow the same pattern.
- **EC Live event photos**: More event photography (attendee shots, session photos) likely exists in the HubSpot file manager but isn't linked from the static pages we could crawl.
- **Success story logos**: Company logos on the success stories page load dynamically via JavaScript filters and couldn't be captured through static page crawling.
- **Academy screenshots**: Only 2 static screenshot images were found. Richer screenshots may be in HubSpot's file manager.
