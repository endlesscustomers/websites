One-sentence: The centered page hero — eyebrow, big Merriweather headline with a brand-blue highlight, subtitle, and CTA row.

```jsx
<Hero eyebrow="Endless Customers" title="Your Path to" highlight="Endless Customers Starts Here"
  subtitle="Become the most trusted voice in your industry."
  primaryCta="Schedule a Call" primaryHref="/schedule"
  secondaryCta="Get the Book" secondaryHref="/book" />
```

Set `onDark` for a dark hero band, `align="left"` for asymmetric layouts.
