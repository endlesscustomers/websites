# V2 Doodle Icon Catalog

Local review URL:

`http://127.0.0.1:8765/design-system/specimens/v2-doodle-icons/`

The catalog reads `assets/icons/doodle/manifest.json`, supports search and
category filtering, previews the original SVG artwork, and copies a valid
`DoodleIcon` component reference for each asset.

This library is optional editorial imagery. It does not replace the governed
interface icons used for navigation, forms, validation, controls, or other
functional UI. Production publishing remains blocked until the source pack's
usage rights are confirmed.
